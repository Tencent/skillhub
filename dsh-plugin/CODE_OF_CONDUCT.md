# 行为准则

本文件参考 [Contributor Covenant](https://www.contributor-covenant.org/) 2.1。

## 我们的承诺

我们致力于为所有参与者提供友善、开放且无骚扰的协作环境，不因年龄、体型、可见或不可见的残障、族裔、性征、性别认同与表达、经验水平、教育、社会经济地位、国籍、外貌、种族、宗教或性取向而区别对待。

## 期望行为

- 尊重不同观点，以事实和技术问题为中心交流
- 给出建设性的反馈，并愿意接受合理的评审意见
- 对社区成员保持耐心，主动帮助新贡献者
- 发现错误时及时更正，为社区着想
- 不进行人身攻击、嘲弄或公开羞辱

## 不可接受的行为

- 侮辱、威胁、骚扰、歧视或持续性的恶意交流
- 发布他人的私人信息、凭证或未授权内容
- 性化的语言、图像，或不受欢迎的性关注
- 垃圾信息、恶意破坏及其他不利于协作的行为
- 其他在专业场合可被合理视为不当的行为

## 执行范围

本准则适用于仓库的 Issue、Pull Request、讨论、提交记录，以及有人代表本项目的其他公共空间。

## 执行

发现违规时，可通过维护者 GitHub 主页私下联系：<https://github.com/Tencent>

维护者有责任澄清行为标准，并可删除、编辑或拒绝不符合本准则的评论、提交、代码、Issue 和其他贡献，必要时说明原因。

## 执行指南

维护者将视影响采取下列措施：

| 程度 | 影响 | 后果 |
| --- | --- | --- |
| 1. 纠正 | 用词不当或不符合专业要求 | 私下警告，可要求公开道歉 |
| 2. 警告 | 单次或系列违规 | 一段时间内限制互动 |
| 3. 暂时限制 | 持续违规或严重影响他人 | 暂时禁止与社区互动 |
| 4. 永久限制 | 长期骚扰、歧视或攻击 | 永久禁止参与 |

举报人的隐私应得到尊重。维护者会根据已掌握的信息尽快处理。

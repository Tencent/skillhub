# 探索策略

先结构后细节，按需深入。

## 步骤

1. **列出文件**：目录树或等价列表（路径 + 大致行数/大小）
2. **必读**：根目录 `SKILL.md`（含 frontmatter 的 `name` / `description`）
3. **优先读**（若存在）：`README.md`、配置（`package.json` / manifest）、主脚本入口、`scripts/` 核心文件
4. **按需读**：`references/`、`examples/`、FAQ、最佳实践文档
5. **大文件**：先读前 50–100 行了解结构，再按需续读；不必通读
6. **停止条件**：已掌握触发方式、能力边界、结构层次、实现完整度与文档质量证据即可结束探索

## 原则

- 不需要读取所有文件；抓住关键文件即可评判
- 评分理由应能追溯到已读路径中的具体内容
- 未读取的文件不得作为正面或负面证据

# Trust（可信 / 本地化适配）

本维度含 2 个子项。**只评 `domestic`；`scan` 固定跳过。**

## scan（安全扫描）— 跳过

本 skill 不做安全扫描，勿编造分数。固定输出：

```json
{
  "status": "skipped",
  "reason": "本评测不做安全扫描，不评分",
  "userReason": "未做安全扫描，此项跳过"
}
```

禁止给其它子项使用 `skipped`。

## domestic（本地化适配）

侧重中文支持与依赖服务是否易于直接使用。5 分制：

| 分 | 标准 |
|----|------|
| 5 | 完全支持中文交互；常用服务/API 兼容；依赖可直接访问；适配主流平台和工具链 |
| 4 | 基本支持中文，少量提示为英文；可正常使用，偶有兼容性小问题 |
| 3 | 部分支持中文，核心功能可用但体验一般；部分依赖不易直接访问 |
| 2 | 中文支持不完整，较多依赖不易直接访问的服务 |
| 1 | 仅支持英文、关键依赖难以直接使用 |

- `score` ∈ `(0, 5.0]`；缺失给 1.0–2.0
- `reason`：开发者视角，可引用文件证据
- `userReason`：普通用户视角，评价质量好坏，勿写功能介绍/文件名/代码术语

维度级也需填写 `reason` / `userReason`（综合 domestic；可注明 scan 已跳过）。

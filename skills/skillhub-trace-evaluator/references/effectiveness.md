# Effectiveness（有效性）

4 个子项：`accuracy`、`completeness`、`usability`、`creativity`。全部须评分；`score` ∈ `(0, 5.0]`；缺失给 1.0–2.0。

对文档型 Skill：依据 SKILL 流程完整性、步骤可执行性、输出模板清晰度与额外价值推断；勿虚构未验证的运行结果。

## accuracy（输出准确性）

| 分 | 标准 |
|----|------|
| 5 | 输出准确、格式规范、语义精准；复杂场景游刃有余 |
| 4 | 整体效果良好，偶有小瑕疵 |
| 3 | 基本可用，部分场景不理想 |
| 2 | 输出质量较差，错误较多 |
| 1 | 错误频繁、格式混乱 |

## completeness（内容完整度）

| 分 | 标准 |
|----|------|
| 5 | 多条件/多步骤/复杂流程覆盖充分 |
| 4 | 大部分复杂场景可处理，少量极端组合有问题 |
| 3 | 简单场景可处理，复杂场景部分不足 |
| 2 | 仅支持简单场景 |
| 1 | 仅支持最简单场景 |

## usability（开箱即用度）

| 分 | 标准 |
|----|------|
| 5 | 调用流程顺畅；参数与返回符合预期；文档与行为一致 |
| 4 | 调用基本顺畅，少量可优化 |
| 3 | 可以调用成功，但流程不够清晰或有小问题 |
| 2 | 调用流程有明显问题 |
| 1 | 无法正常调用、流程不清晰 |

## creativity（创造力与增值）

| 分 | 标准 |
|----|------|
| 5 | 术语统一、有额外洞察与创新方案；超出预期 |
| 4 | 有一定创新性与额外价值 |
| 3 | 基本满足需求，缺乏创新 |
| 2 | 仅最基本回答 |
| 1 | 敷衍、缺乏深度 |

每子项：`reason` + `userReason`。维度级填写 `reason` / `userReason`。

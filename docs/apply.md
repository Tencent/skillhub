# 联系我们

如果你计划把 SkillHub 接入正式产品，或需要更大的调用容量、沙箱与模型资源、技术支持或商务合作，欢迎联系我们。

## 适合联系我们的场景

- 高 QPS、高并发、批量下载或全量数据同步
- Sandbox Run、Agent 会话、流式输出、大文件处理或模型调用
- 接入官方平台、企业产品、行业门户或其他生产系统
- 付费 Skill、商业分发、品牌合作或联合运营
- 需要专属配额、上线联调或稳定性保障

## 邮件中请说明

- 公司、团队与产品名称
- 产品地址或介绍材料
- 使用场景和目标用户
- 计划使用的 API 或能力
- 预计 DAU、QPS、日调用量和峰值并发
- 是否使用沙箱、文件、长连接或模型 Token
- 是否用于官方平台或商业化项目
- 期望上线时间
- 技术和商务联系人

信息越完整，我们越容易快速判断现有容量是否合适，并给出配额、接入和上线建议。

## 联系方式

邮件标题建议使用：

```text
[SkillHub API 合作] 团队名 - 产品名 - 场景简称
```

> **联系邮箱：[skillhub@tencent.com](mailto:skillhub@tencent.com)**

## 服务说明

未提前沟通的调用会使用共享资源。服务繁忙时可能出现限流或降级，请正确处理 `429`、`5xx`、超时和重试。

如果 SkillHub API 是你的关键生产依赖，请在上线前联系我们确认可支持的调用规模和稳定性方案。

# 使用说明

SkillHub Open API 可以接入 Agent、IDE、企业门户、技能广场和自动化工作流。

## 你可以用它做什么

| 你想做什么 | 可以使用的能力 |
|------------|----------------|
| 搭建技能广场或产品内搜索 | Skill 搜索、分类、榜单、推荐和详情 |
| 展示并安装 Skill | 文件、版本、版本差异和下载 |
| 帮助用户了解 Skill 质量 | 评测、测试用例、签名和验签 |
| 发布和维护 Skill | 发布、GitHub 导入、版本和可见性管理 |
| 管理企业内部 Skill | 私有 Skill、组织分类、成员和审核 |
| 在产品中运行 Skill | 沙箱、会话、流式输出和文件处理 |
| 接入付费或行业内容 | 付费 Skill、专家包和行业 Skill |

接口说明见 [API 参考](api/README.md)，更多文档会陆续补充。访问组织内的 Skill 和数据时，需要相应的成员权限。

## 日常开发与测试

个人项目、功能验证和低频调用可以直接按文档接入。使用时请注意：

- 服务繁忙时可能触发频率或并发限制
- 请正确处理 `429`、`5xx`、超时和重试
- 下载地址、临时凭证和部分运行结果可能有有效期
- 请只依赖文档中明确说明的字段和行为

各接口的具体要求以对应文档为准。

## 生产接入与资源支持

如果有以下计划，建议在上线前联系我们：

| 场景 | 我们可以一起确认 |
|------|------------------|
| 高 QPS、高并发或全量同步 | 调用容量、限额、缓存和批量方案 |
| 沙箱、Agent 会话或模型调用 | 并发、执行时长、文件上限和 Token 用量 |
| 接入官方平台或企业级产品 | 上线联调、容量评估、监控和故障响应 |
| 付费 Skill、联合运营或正式商用 | 产品方案、授权方式和商务合作 |
| 需要专属配额或稳定性保障 | 可支持的容量、服务目标和技术支持 |

未提前沟通的调用使用共享资源，繁忙时可能出现限流或降级，不建议直接用于关键生产链路。联系信息和建议提供的材料见 [联系我们](apply.md)。

## 使用范围

平台管理、内部系统和其他组织的私有数据不提供公开访问。
